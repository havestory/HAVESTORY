# PrintBloom Website Project Overview

## Project Summary

PrintBloom needs a modern, premium website for a printing and graphic design business. The website should have a **pink–purple light glass** visual style with a **creative, modern, user-friendly interface**, attractive animations, and a polished Web UI.

The site should help customers:

* Explore products and services
* Place custom print orders easily
* Track orders
* View the company portfolio
* Contact the business quickly
* Reach the business through WhatsApp and contact forms

The platform should also include a strong **admin panel** so the PrintBloom team can manage products, services, portfolio items, customer messages, reviews, counts, images, and website content in one place.

---

## Main Website Goals

1. Create a premium and trustworthy brand presence
2. Make ordering custom print products simple
3. Present services in a clear categorized structure
4. Showcase the company’s portfolio beautifully
5. Display live business statistics in real time
6. Improve communication through forms, WhatsApp, and message management
7. Give admins full control over content and updates

## Admin Panel Requirements

The admin panel should be the complete control center for the entire website, giving admins access to manage **all website content, customer activity, order flow, finance records, reports, agreements, catalog items, inventory, notices, and settings**.

### Core Admin Access Principle

* Admin must be able to update **all website details** without coding
* All approved changes should reflect on the website in real time or immediately after saving/publishing
* Admin permissions should allow full content editing, management, and monitoring
* Website editor should be a **separate section inside the admin panel** for easier content control
* Admin should be able to preview changes before publishing where needed
* Every important update should be saved securely in the system database

## Real-Time Dynamic Data Requirements

The following website and admin data should update automatically from backend/admin data:

* Happy Clients
* Product Types
* Orders Delivered
* Star Rating
* Featured products
* Featured services
* Latest approved reviews
* Active notices
* Order tracking statuses
* Portfolio/project updates
* Invoice/payment status where applicable

### Real-Time Update Principle

* Any content saved by admin should update on the website immediately or after publish confirmation
* Approved reviews should appear automatically in the review section
* Newly featured products/services should reflect on homepage sections instantly
* Order tracking updates should be visible immediately to customers
* Notice changes should display across the website based on active status
* Dashboard counts should refresh automatically
* Finance summaries and reports should use current saved data

### Logic Suggestions

* Happy Clients = number of approved/active clients in database
* Product Types = number of active products + service types
* Orders Delivered = number of orders marked completed
* Star Rating = average approved rating from reviews or admin override setting
* Active Notices = notices enabled and valid by schedule/date
* Project Count = active or completed projects saved by admin
